# Third-party code

- **BakkesMod SDK**: headers and `pluginsdk.lib`, from the BakkesMod install (`BakkesMod.props`).
- **BakkesmodPluginTemplate** (Martinii89, https://github.com/Martinii89/BakkesmodPluginTemplate): project setup, `logging.h`, `update_version.ps1`, `resource.h`, by way of `nexto-sparring`.

## Read for reference, nothing copied

- **FastAerialTrainer** (no licence found): event names and the idea of hooking them.
- **SpeedFlipTrainer** (tynidev, GPL-3.0, https://github.com/tynidev/SpeedFlipTrainer): that `GetDodgeDirection()`, `IsDodging()` and the engine physics frame counter exist and how they behave.
